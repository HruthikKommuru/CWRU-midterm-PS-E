# Data dictionary

| File or column | Meaning |
| --- | --- |
| inputs/batch_report.md | Laboratory findings and product records. |
| inputs/sales_records.csv | Store transactions summarized by batch and date span. |
| sales_records.store_id | Store identifier in the sales system. |
| sales_records.batch | Production batch recorded for the sale. |
| sales_records.units_sold | Number of bottles sold. |
| sales_records.sale_dates | Inclusive dates covered by the row, in YYYY-MM-DD format. |
| inputs/store_list.csv | Operating store directory. |
| store_list.store_id | Store identifier in the directory. |
| store_list.name | Store trading name. |
| store_list.address | Store mailing address. |
| store_list.phone | Store telephone number. |
| inputs/regulator_form.md | Fields in the Board submission form. |
| inputs/company_policy.md | Customer service procedures and directory administration. |
